# 🔐 PassGen - Password Manager

PassGen is a simple and user-friendly password manager built with Python and CustomTkinter. It allows users to securely store and manage their passwords for various websites. The application supports user authentication and provides a clean graphical interface for managing passwords.

---
## 🚀 Features

- **User Authentication**: Sign up and log in with secure credentials.
- **Password Management**: Add, view, and manage passwords for different websites.
- **Modern UI**: Built with CustomTkinter for a sleek and responsive interface.
- **Drag-and-Drop Windows**: Easily move application windows around the screen.
- **Data Persistence**: User and password data are stored in JSON files.

---

## 🛠️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/PassGen.git
   cd PassGen
   ````
2.Install the required dependencies:
```
pip install customtkinter pillow
```
3.Run the application:
```
python login.py
```


**📖 Usage**

- Sign Up: Create a new account by entering a username and password in the signup window.

- Log In: Use your credentials to log in to the application.

**Manage Passwords:**

- Add new entries for websites, emails, and passwords.
- View existing entries in a table format.

**📂 Data Storage**

- User Data: Stored in users.json.

- Password Data: Stored in pass.json.
  
**🛡️ Security**

- Passwords are stored in plain text in the JSON file. For production use, consider encrypting the data using libraries like cryptography or hashlib.
